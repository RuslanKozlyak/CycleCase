# Комфортный маршрут на велосипеде

Постройте удобные маршруты для человека на городском велосипеде.
В наборе — дороги Констанца, данные о поездках и 36 пар точек A–B.

## Установка

Нужен Python 3.11+. Клонируйте репозиторий или скачайте **Code → Download ZIP**.
Команды выполняйте из папки проекта.

```bash
git clone https://github.com/RuslanKozlyak/CycleCase.git
cd CycleCase
```

Windows (PowerShell):

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .
.\.venv\Scripts\jupyter-lab.exe notebooks/hackathon_konstanz.ipynb
```

macOS / Linux:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -e .
.venv/bin/jupyter-lab notebooks/hackathon_konstanz.ipynb
```

В Jupyter выберите Python из `.venv`, включите **Trust Notebook** и выполняйте ячейки сверху вниз.

## Что есть в проекте

Для своего города укажите полные адреса и включите `RUN_ADDRESSES`: данные загрузятся автоматически.

## Работа с ноутбуком

Меняйте ячейки с ✏️: признаки, веса, стоимость, повороты, поиск и модель.
Справочники `data_dictionary(city)` и `points_dictionary(city)` описывают дороги и точки.
Точки доступны через `city.points`; их набор может быть неполным.

`city.trips` — открытые измерения поездок: `NaN` означает отсутствие измерения, `0` — измеренный ноль.
Сравнивайте маршруты на карте и добавляйте свои показатели.

## Оценка и сдача

Место в рейтинге определяет **популярность**, от 0 до 100: среднее по всем заданным парам.
Внутри маршрута популярность участков усредняется с учётом длины.
Для участка без измерения используется 50, для пары без маршрута — 0.

За рейтинг можно получить **40 баллов**, за защиту — **60 баллов**.
На защите объясните, почему маршруты подходят городскому велосипедисту.
