# CicleGpx

Небольшой проект для анализа и визуализации велотреков Garmin в формате GPX.

## Быстрый старт (PowerShell)

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -e .
.\.venv\Scripts\jupyter-lab.exe
```

Откройте `notebooks/visualize_gpx.ipynb`. Ноутбук автоматически ищет GPX-файлы в каталоге `cicle_gpx/`, очищает дубли и GPS-выбросы, ограничивает точки областью Санкт-Петербурга и строит геометрии в `EPSG:4326` и метрическом `EPSG:32636`. Затем он формирует таблицу поездок, интерактивную карту и профиль высоты. В разделе анализа популярности он также показывает поездки по времени, тепловую карту повторяющихся коридоров и наиболее похожие пары маршрутов.

## Основные библиотеки

- `gpxpy` — чтение GPX и работа с треками/сегментами;
- `GeoPandas`, `Shapely` — геометрии и геоданные;
- `pyproj` — системы координат и геодезические расстояния;
- `Folium` — интерактивная карта;
- `pandas`, `Matplotlib` — анализ и графики;
- `JupyterLab`, `ipykernel` — запуск ноутбука.

GPX-файлы остаются исходными данными и не изменяются.
