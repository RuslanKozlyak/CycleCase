# Комфортный маршрут на велосипеде

Постройте удобные маршруты для человека на обычном городском велосипеде.
Основной набор — дороги Констанца, данные о поездках и 36 пар точек A–B.

## Установка

Нужен Python 3.11 или новее. Клонируйте репозиторий или скачайте **Code → Download ZIP** и распакуйте архив.
Откройте терминал в папке с `pyproject.toml`.

```bash
git clone https://github.com/RuslanKozlyak/CycleCase.git
cd CycleCase
```

Windows (PowerShell):

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .
.\.venv\Scripts\jupyter-lab.exe notebooks/hackathon_konstanz.ipynb
```

macOS / Linux:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -e .
.venv/bin/jupyter-lab notebooks/hackathon_konstanz.ipynb
```

В Jupyter выберите Python из `.venv` и выполняйте ячейки сверху вниз.
Для интерактивных карт при необходимости включите **Trust Notebook**.

## Что есть в проекте

| Путь | Содержимое |
| --- | --- |
| [Учебный ноутбук](notebooks/hackathon_konstanz.ipynb) | Данные, настройки, обучение, сравнение и сдача решения |
| [Шпаргалка](LIBRARIES_CHEATSHEET.md) | pandas, NetworkX и scikit-learn |
| `notebooks/data/hackathon/konstanz/` | Дороги, открытые измерения, пары A–B, зоны и точки |
| `notebooks/data/hackathon/saint_petersburg/` | Пример Петербурга с маршрутами и подготовленными GPX |
| `cicle_gpx/` | 19 исходных GPX для примера Петербурга |
| `src/cycle_routing/` | Функции работы с данными, маршрутами и картами |

Данные входят в репозиторий. Для Констанца и готового примера Петербурга скачивать их заново не нужно.
В Петербурге сохранены все подготовленные GPX; сеть дополнена Петроградской стороной,
Крестовским и Каменным островами и дорогами в пределах 500 м от GPX.
Карта работает без интернета; фоновая карта OSM подгружается при её включении.
В разделе «Свои адреса» можно указать два полных адреса с городом и включить `RUN_ADDRESSES`.
Для этого раздела нужен интернет: дорожная сеть, точки и система координат подготавливаются автоматически.

## Работа с ноутбуком

Меняйте ячейки с ✏️: признаки дорог, веса, формулу стоимости, штрафы за повороты, поиск и модель.
Все участки исходной сети доступны. Справочники `data_dictionary(city)` и `points_dictionary(city)`
показывают имеющиеся столбцы и типы точек. Наборы точек доступны по названию через `city.points`.
Точки собраны не полностью: отсутствие точки в наборе не доказывает её отсутствие на улице.

`city.trips` содержит число поездок по участкам в открытой зоне. `NaN` означает отсутствие измерения,
а `0` — измеренный ноль. Закрытые измерения для обучения недоступны.
Веса и модель в ноутбуке — начальные примеры. Сравнивайте маршруты на карте и добавляйте свои показатели.

## Оценка и сдача

Место в рейтинге определяет **популярность**: среднее значение по всем заданным парам.
Популярность маршрута — средняя популярность его участков с учётом их длины, от 0 до 100.
Шкала строится по открытым измерениям: чем больше поездок по участку, тем выше его значение.
Для участка без измерения используется 50; для пары без маршрута — 0.
Это показатель использования улиц, а не процент велосипедистов, выбравших ваш маршрут.

За рейтинг можно получить **40 баллов**, за защиту — **60 баллов**.
На защите объясните свои решения и покажите, почему маршруты подходят городскому велосипедисту.
Можно добавить собственные показатели в таблицу сравнения.

В последней ячейке выберите решение и выполните экспорт.
Сдайте учебный ноутбук и папку `outputs/hackathon/konstanz/submission/`.
