# CicleGpx

## Экспериментальный ноутбук

`notebooks/comfort_routing.ipynb` сравнивает кратчайший маршрут с маршрутами по пресетам предпочтений (сбалансированный, быстрый, минимум поворотов, спокойный, велоинфраструктура и др.). Основной эксперимент — Konstanz: пресеты проверяются на реальных потоках STADTRADELN 2024. Личные GPX Санкт-Петербурга — дополнительная проверка; демонстрационный маршрут «Гражданский проспект, 27 к2» → «Биржевая линия, 14».

Ноутбук содержит только параметры, вызовы и отображение. Код — пакет `cycle_routing` в `src/`, по модулю на этап:

1. `data.py` — скачивание и загрузка STADTRADELN и GPX;
2. `graph.py` — OSM-граф: кэш, переключение Overpass endpoints, проекция;
3. `matching.py` — привязка STADTRADELN и GPX-треков к рёбрам графа;
4. `comfort.py`, `routing.py`, `config.py` — веса комфорта, пресеты, штрафы поворотов, построение маршрутов;
5. `evaluation.py` — метрики готовых маршрутов;
6. `visualization.py` — карты.

Граф скачивается целиком (`network_type="all"`) вместе с непроезжими дорогами и тротуарами. Три точки расширения, каждая — обычная функция:

- **фильтр рёбер** `keep_edge(tags) -> bool` (по умолчанию `is_rideable`) — передаётся в `load_graph`;
- **функция стоимости** `cost(tags) -> метры` — ключ `cost` пресета, вместо весов `config`;
- **алгоритм поиска** `search(graph, origin, destination, weight, turns) -> рёбра` — ключ `search` пресета; готовые `dijkstra` и `dijkstra_turns`.

Для покрытия всего немецкого набора используется `network_type="bike", simplify=True, retain_all=True`. Это важно: `retain_all=False` отбрасывает компоненты наблюдаемой сети. Упрощение OSMnx сохраняет составные `osmid` и почти не ухудшает матч, но заметно уменьшает граф.

Небольшой проект для анализа и визуализации велотреков Garmin в формате GPX.

## Быстрый старт (PowerShell)

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -e .
.\.venv\Scripts\jupyter-lab.exe
```

Откройте `notebooks/comfort_routing.ipynb`. Ноутбук автоматически читает GPX-файлы из каталога `cicle_gpx/`, очищает дубли и GPS-выбросы, строит OSM-графы и выполняет эксперименты для Санкт-Петербурга и Констанца.

## Основные библиотеки

- `gpxpy` — чтение GPX и работа с треками/сегментами;
- `GeoPandas`, `Shapely` — геометрии и геоданные;
- `pyproj` — системы координат и геодезические расстояния;
- `Folium` — интерактивная карта;
- `pandas` — таблицы и анализ;
- `tqdm` — индикаторы прогресса загрузки и построения маршрутов;
- `JupyterLab`, `ipykernel` — запуск ноутбука.

GPX-файлы остаются исходными данными и не изменяются.
