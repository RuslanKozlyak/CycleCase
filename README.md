# CicleGpx

## Экспериментальный ноутбук

`notebooks/comfort_routing.ipynb` строит shortest-, исходный comfort- и оптимизированный comfort-маршруты. Популярность не входит в признаки маршрута при инференсе: STADTRADELN используется как целевая переменная для подбора весов и для отложенной проверки, а личные GPX Санкт-Петербурга — как внешний тест переноса. Для демонстрационного маршрута используются адреса из OSM: «Гражданский проспект, 27 к2» → «Биржевая линия, 14».

Ноутбук содержит только конфигурацию, вызовы и отображение. Рабочий код оформлен как пакет `cycle_routing` в `src/`:

- `osm.py` — семантический кэш графов и переключение между Overpass endpoints;
- `matching.py` — проверяемая привязка STADTRADELN к OSM по ID и геометрии;
- `comfort.py` — рёберная функция стоимости;
- `optimization.py` — пространственное train/validation/test-разбиение и подбор весов по популярности с ограничением объезда;
- `routing.py`, `evaluation.py` — маршруты, геометрические штрафы за повороты и метрики экспериментов;
- `gpx.py`, `datasets.py` — чтение исходных данных;
- `visualization.py` — карты и графики.

Для покрытия всего немецкого набора используется `network_type="bike", simplify=True, retain_all=True`. Это важно: `retain_all=False` отбрасывает компоненты наблюдаемой сети. Упрощение OSMnx сохраняет составные `osmid` и почти не ухудшает матч, но заметно уменьшает граф.

Небольшой проект для анализа и визуализации велотреков Garmin в формате GPX.

## Быстрый старт (PowerShell)

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -e .
.\.venv\Scripts\jupyter-lab.exe
```

Откройте `notebooks/comfort_routing.ipynb`. Ноутбук автоматически читает GPX-файлы из каталога `cicle_gpx/`, очищает дубли и GPS-выбросы, строит OSM-графы и выполняет эксперименты для Санкт-Петербурга и Констанца. Профиль оптимизации `full` используется по умолчанию; для быстрой проверки ячеек можно переключить `OPTIMIZATION_PROFILE` на `quick`.

## Основные библиотеки

- `gpxpy` — чтение GPX и работа с треками/сегментами;
- `GeoPandas`, `Shapely` — геометрии и геоданные;
- `pyproj` — системы координат и геодезические расстояния;
- `Folium` — интерактивная карта;
- `pandas`, `Matplotlib` — анализ и графики;
- `tqdm` — индикаторы прогресса загрузки, оптимизации и сравнения маршрутов;
- `JupyterLab`, `ipykernel` — запуск ноутбука.

GPX-файлы остаются исходными данными и не изменяются.
